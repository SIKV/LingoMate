# 💬 LingoMate

LingoMate is a simple, AI-powered chat app designed to help you learn and practice languages through natural, interactive conversations.

### ✨ Features

- Smart AI conversations for language practice, powered by your own OpenAI API key
- Per-turn corrections and feedback on grammar, vocabulary, and phrasing
- Optional live translation into a second language of your choice
- Choice of OpenAI model, balancing quality and cost
- Settings are saved locally in your browser, no account needed

### 🌐 Supported Languages

Pick any pair on the Chat tab — one language to practice, another to translate into (or no translation at all):
